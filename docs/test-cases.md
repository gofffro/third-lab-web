# Сценарии ручной проверки

| № | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Создать список «Работа» | Он появился в панели, открылся, URL содержит идентификатор. |
| 2 | Добавить задачу и перейти в другой список | Задача видна только в исходном списке, счётчики верны. |
| 3 | Выбрать «Активные», открыть карточку и обновить страницу | Карточка и фильтр восстановились. |
| 4 | Открыть несуществующую задачу | Показано «Задача не найдена» и ссылка на список. |
| 5 | Открыть `/abc` | Показана страница «не найдено» со ссылкой на старт. |
| 6 | Добавить 3 подзадачи и отметить 2 | В карточке и строке задачи отображается `2/3`. |
| 7 | Очистить название в карточке и уйти с поля | Старое название сохранено. |
| 8 | Быстро набрать запрос | Результат обновляется после паузы около 300 мс. |
| 9 | Ввести отсутствующее слово и сбросить поиск | Показано пустое состояние, после сброса видны все задачи. |
| 10 | Ввести запрос и перейти в другой список | Поисковое поле нового списка пустое. |
| 11 | Включить тёмную тему и обновить | Тёмная тема применяется без вспышки светлой. |
| 12 | Удалить открытый список и подтвердить | Список и задачи удалены, открыта стартовая страница. |
| 13 | Открыть удаление и нажать Escape | Диалог закрыт, фокус возвращён кнопке удаления. |
| 14 | Перейти в другой список клавиатурой | Фокус на заголовке нового списка. |
