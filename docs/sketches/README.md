# Эскизы новых экранов

Новые экраны спроектированы в стилистике макета Л2 прямо в приложении:

- боковая панель списков — тёмный блок с оранжевым активным индикатором;
- карточка задачи — светлая/тёмная модальная панель поверх списка;
- тёмная тема — те же токены макета `1B1A17`, `1F1E1B`, `A35709`, `FF8303`, `F0E3CA`.

Реализация и контрольные состояния находятся в `src/styles/base.css` и компонентах `Sidebar` / `TaskPage`.
