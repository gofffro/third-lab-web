# Focus — менеджер задач на React

Лабораторная работа 3: перенос приложения из Л2 на React 19, Vite и React Router. Визуальная основа — макет [To-Do List (Community)](https://www.figma.com/design/U09ssoBkhIpaSLmO5v0AQ7/To-Do-List-(Community)); палитра сохранена в `src/styles/tokens.css`.

## Запуск

```bash
npm install
npm run dev
```

Перед сдачей полезно выполнить `npm run lint` и `npm run build`. Для просмотра сборки: `npm run preview`.

## Возможности

- списки задач: создание, переименование, удаление с подтверждением и счётчик активных задач;
- задачи: добавление, отметка выполнения, редактирование в карточке, удаление;
- подзадачи с добавлением, отметкой, удалением и индикатором «выполнено N из M»;
- адреса списков и задач, фильтр и поиск в строке запроса;
- поиск с задержкой 300 мс и отдельное состояние отсутствия результатов;
- тёмная тема в стилистике макета и светлая альтернатива с сохранением выбора;
- localStorage, пустые состояния, обработка неизвестного адреса, клавиатурная навигация и адаптация для 360/768/1280 px.

## Принятые решения

Отметка самой задачи не изменяет автоматически отметки подзадач: это независимые уровни прогресса. На узком экране боковая панель открывается кнопкой меню и закрывается по ссылке, Escape не требуется для обычной навигации. Карточка задачи открывается поверх списка, поэтому кнопка браузера «назад» возвращает к тому же списку и фильтру. При переходе в другой список поисковый запрос очищается: запрос относится только к текущему списку.

## Перенос с Л2

Модули `state.js`, `view.js` и ручная работа с DOM заменены компонентами React. Данные обновляются только через `useReducer`, а контекст передаёт состояние и `dispatch` дереву компонентов. Сохранение осталось в браузере, но ключ обновлён до `todo-app:v2`; повреждённые данные безопасно заменяются пустым состоянием.
